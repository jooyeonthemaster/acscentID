# 화면 배경 에셋

포토부스와 키오스크에 각각 36종을 준비했습니다. 각 기기별로 실제 포스터 기반 신규 배경 20종, 이전 디자인 검토 배경 10종, 기존 공용 배경 6종을 포함합니다. UI 목업·레퍼런스 포스터·인물 컷아웃·인화 프레임은 포함하지 않습니다.

- 포토부스: 1920 × 1080px WebP, 썸네일 384 × 216px
- 키오스크: 1080 × 1920px WebP, 썸네일 216 × 384px
- 전체 72개 배경과 72개 썸네일, 총 144개 이미지
- 최초 생성 기준 전체 이미지 용량 8,908,694바이트(약 8.50MiB)

신규 키오스크 20종은 처음부터 세로형으로 제작된 이미지를 사용합니다. 이전 키오스크 검토 배경 10종과 공용 배경 6종은 가로 원본을 중앙 기준 `cover` 방식으로 잘라 세로 화면에 맞췄습니다. 이 16종은 좌우 가장자리 장식이 일부 보이지 않을 수 있습니다. 원본 파일은 모두 그대로 보존했습니다.

카탈로그는 `src/lib/screen-backgrounds/catalog.json`에 있습니다. `poster`, `study`, `legacy` 순으로 정렬하며 ID는 기기·컬렉션·번호 또는 이름으로 고정됩니다. 각 항목에 제목, 이미지·썸네일 URL, 폰트 계열, 명암, 글자색·강조색·기본색을 포함합니다.

저장소 루트에서 `node scripts/prepare-screen-backgrounds.mjs`를 실행하면 기존 원본으로 에셋과 카탈로그를 다시 만들 수 있습니다. 원본 경로·크기·변환 방식·개별 용량은 `design-review/screen-backgrounds-asset-report.json`에 기록합니다. 이 에셋 빌드는 앱의 현재 배경 선택이나 사용자 설정을 변경하지 않습니다.
