# 키오스크 영상판 — COLOR! · DRAW! · MAKEUP! (2026-11-18)

길잡이 인물 영상을 컷 · 빈 화면 없이 잇는 키오스크 영상판의 화면용 영상 · 그림. 재생기 `src/app/kiosk/video/stage.tsx`, 계획 · 흐름 `src/app/kiosk/video/plans.ts`, 미리보기 `/kiosk/video/<프로그램>`.
만든 방법은 `.claude/skills/kiosk-video-flow`(SIP! 소믈리에 영상판과 같은 구조).

| 폴더 | 길잡이 | 장면(차례) |
|---|---|---|
| `color/` | 컬러리스트 「서하」(회색 옷만 — 손님 얼굴에 색이 비치지 않게) | door 아틀리에 입구 → desk 상담 탁자(이름 · 성별) → window 북쪽 창가(촬영) → drape 드레이프(AI 분석) → mirror 거울(결과) |
| `draw/` | 거리 화가 「모루」(코럴 반다나) | steps 계단 골목 → frame 언덕 화실(촬영) → measure 연필로 재기(확인) → tools 도구 탁자(화풍) → paint 이젤 뒤(그리는 중) → reveal 이젤 돌려 공개(결과) |
| `makeup/` | 메이크업 아티스트 「이안」(모브 브러시 벨트) | curtain 백스테이지 커튼 → vanity 전구 거울(촬영) → palette 팔레트(편집) → hair 헤어 스테이션(머리 모양 · AI) → runway 런웨이 입구(결과) |

- 장면마다 `hi-<장면>.mp4`(도착 인사 4초) · `idle-<장면>-1|2.mp4`(대기 4초). 첫 · 끝 프레임 = 그 장면 그림 `<장면>.webp`(인사 조각 첫 프레임에서 뽑음).
- 이동: `move-<도착>.mp4`(차례대로 다음 장면) · `move-<떠남>-<도착>.mp4`(되돌아가기 · 건너뛰기 · 다음 손님). 다른 장소면 8초(걸어 나가고 · 1인칭으로 길을 가고 · 걸어 들어옴), 같은 자리면 4초(자세만 바꿈).
- 결과 면(거울 · 캔버스 · 즉석 사진)은 영상 내내 비어 있고, 화면이 매 프레임 그 면 색인 곳에만 결과를 얹는다(`SurfaceArt`). `sample.webp` 는 미리보기용 가상 인물 견본.
- 모두 소리 없음 · 720×1280 · 30fps · H.264 crf 23 · faststart.
- 원본(2K 그림 · 생성 원본 mp4 · 비용 기록 `_log.jsonl` · 만든 도구)은 저장소 밖 `design-review/kiosk-cast/`. 생성은 Wan 3.0(오픈라우터 영상 API), R&D 키.

## 실제 프로그램에 붙임(2026-11-18) — 데모 `/kiosk-demo/video`

기본 프로그램 · 기존 데모(`/kiosk-demo`)는 그대로 두고, 주소에 `&lab=video` 가 있을 때만 영상판이 뜬다(사용자 지시).

| 프로그램 | 주소 | 화면 | 같이 쓰는 것 |
|---|---|---|---|
| COLOR! | `/kiosk?mode=ai-color&demo=1&lab=video` | `src/app/kiosk/video/ColorVideo.tsx`(KioskScreen 이 고름) | 진단 요청 `/api/kiosk/analyze/color` · `colorFocusFor` · 결과지 `ColorReportView` |
| DRAW! | `/kiosk?mode=studio-draw&demo=1&lab=video` | `experience/draw/DrawVideo.tsx`(ExperienceApp 의 VIDEO_MODES) | `useDrawFlow()` — 기본 화면과 같은 촬영 · 그림 요청 · 포스터 · 영수증 |
| MAKEUP! | `/kiosk?mode=studio-makeup&demo=1&lab=video` | `experience/makeup/MakeupVideo.tsx` | `useMakeupFlow()` — 같은 얼굴 찾기 · 화장 · 머리 모양 요청 · 저장 |

- 장면 ↔ 단계: COLOR! 입구 → 상담(이름 · 성별) → 창가(촬영 · 확인) → 드레이프(진단) → 거울(내 사진, 결과지는 「자세히 보기」). DRAW! 계단 → 화실(카메라 카드) → 재기(확인) → 도구(화풍) → 이젤 뒤(그리기) → 캔버스. MAKEUP! 커튼 → 화장대(거울 안이 카메라 · 전후 비교, 아래 편집 도구) → 머리 모양을 바꾸는 동안 헤어 스테이션 → 화장대 → 팔레트를 거쳐 런웨이(즉석 사진).
- 바로 가는 이동 영상이 없으면 한 장면을 거쳐 간다(stage.tsx `hop` — 화장대 → 팔레트 → 런웨이 · 헤어). 그것도 없으면 컷.
- 실제 흐름용 이음 영상 3개를 더 만들었다: DRAW! paint → tools(그림 실패), MAKEUP! hair → vanity(머리 모양 뒤), runway → vanity(다시 꾸미기). $1.26.
- 「처음으로」: 결과 화면에서는 길잡이가 처음 장소로 걸어 돌아간다. 다른 단계에서는 화면 틀이 새로 띄운다(컷 — 첫 영상을 다시 받는 0.1~3.5초 동안 장면 그림이 보임).
- 미리 받기는 가는 차례대로 두 개씩(`preloadPlan`) — 한꺼번에 받으면 다음 조각이 밀려 장면 그림만 7초 보인 적이 있다.
- 대사는 기본 화면의 문구(5개 언어)를 쓴다. COLOR! 첫 인사만 새로 썼다. COLOR! 영상판에는 영수증 · 휴대폰으로 받기가 아직 없다(결과지 화면까지).
- 확인(2026-11-18, 실제 Chrome · 가짜 카메라 = 가상 인물 견본 · AI 요청은 견본으로 가로채 비용 없음 · COLOR! 는 mock=1): 세 프로그램 처음부터 결과 · 다시 · 처음으로까지, 빈 프레임 COLOR! 0 · MAKEUP! 0 · DRAW! 처음으로 새로 띄울 때만 0.02~0.8초. 기본 화면 세 개는 그대로 뜸.

### DRAW! 그리기 · 공개 장면 다시 그림(2026-11-18 사용자 지적)
- 그리기(paint): 예전엔 모루가 정면 캔버스 뒤에서 허공에 붓질 → 이젤을 비스듬히 돌려(앞면은 모루 쪽, 손님에겐 뒷면 · 옆면만) 옆에서 붓끝이 캔버스 면에 닿게.
- 공개(reveal): 예전엔 손이 캔버스 앞을 가림 → 세로(3:4) 큰 캔버스, 손은 캔버스 옆 아래. 결과 자리 `{ x: 50, y: 268, w: 276, h: 362 }`.
- 그 두 장면의 조각 6 + 닿는 이동 5 를 다시 만들었다($3.48). 첫 번째 다시 만들기($3.48)는 생성 도구가 줄인 그림을 경로만으로 캐시해 옛 그림으로 만들어져 버렸다 — `wan-clips.mjs` 가 캐시 이름에 파일 수정 시각 · 크기를 넣게 고쳤다.
