# SAJU! 사주 영상판 영상(연말 시상식, 2026-11-18)

오리지널 캐릭터 관상감 천문 관원 「하율」이 밤의 관상감에서 손님을 맞아 만세력으로 생년월일을 찾고, 구리거울로 한 컷 찍고, 관측대 별밤에 사주를 세워 정미년 첫 해돋이에 사주 카드를 보여 주는 영상(주소 `&lab=video`, `src/app/booth/programs/video-stage.tsx` 의 SAJU).
짜임은 `.claude/skills/kiosk-video-flow` — 장면마다 조각 영상, 장면 사이 이동 영상, 모든 조각의 첫 · 끝 프레임 = 그 장면 그림(정확히 1920×1080 으로 자른 그림). 캐릭터 · 장면 그림은 Gemini 3 Pro Image, 영상은 Wan 3.0 1080p(R&D 키). 원본 design-review/nh-saju-art(저장소 밖). 글자 · 로고 · 소리 없음.

- 장면 그림 `gate`(밤의 관상감 마당) · `library`(만세력 서고) · `mirror`(둥근 구리거울 — 카메라가 거울 안에 뜬다) · `sky`(관측대 별밤 · 혼천의) · `card`(정미년 첫 해돋이 — 받침대 없이 하율이 오른쪽을 가리킨다, 결과는 그 자리에 펼쳐지는 족자 UI · 2026-11-18 다시)
