# CHEESE! 스튜디오 영상판 — 포토그래퍼 온유

`video-stage.tsx` 의 `CHEESE` 가 쓴다(2026-11-25). 장면 그림(webp)은 조각 영상의 첫 · 끝 프레임과 같은 그림이다.

| 장면 | 그림 | 조각 |
|---|---|---|
| 입구 라운지(시작) | lounge.webp | hi-lounge · idle-lounge-1 · idle-lounge-2 |
| 카메라 뒤(네 컷 촬영) | camera.webp | hi-camera · idle-camera-1 · idle-camera-2 |
| 모니터석(프레임 고르기) | monitor.webp | hi-monitor · idle-monitor-1 · idle-monitor-2 |
| 인화 데스크(인화 · QR) | print.webp | hi-print · idle-print-1 · idle-print-2 |

이동: move-camera(라운지→카메라) · move-monitor · move-print · move-lounge(봉투 건네고 배웅 → 라운지). 모두 1920×1080 · 30fps · 소리 없음.
원본 · 도구 · spec 은 저장소 밖 `design-review/cheese-art`(Wan 3.0 1080p, R&D 키). 자세한 기록은 docs/photobooth-programs.md 「CHEESE!」.
