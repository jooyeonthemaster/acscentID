# 포토부스 카운터 이용권

2026-09-24. 카운터에서는 키오스크와 포토부스가 보이지 않는다. 그래서 부스 이용량은 **직원이 결제 후 카운터에서 뽑아 주는 이용권 장수**로만 통제한다.

## 흐름

1. 손님이 카운터에서 결제한다.
2. 직원이 카운터 PC의 `/booth/counter` 화면에서 인원수 버튼(1~4장)을 누른다.
3. 영수증 프린터에서 이용권 쪽지(6자리 번호)가 한 장씩 나온다.
4. 손님이 부스에서 촬영 방식을 고른 뒤 쪽지의 **QR을 부스 카메라에 보여 주거나** 번호를 입력한다. 한 번 쓰면 끝이다.

## 규칙

- **유효기간:** 카운터 발급분은 **발급 시각부터 30분**(기본)만 쓸 수 있다. 카운터 화면의 '유효 시간'에서 5분 단위로 5분~24시간까지 바꿀 수 있다(빠른 선택: 15분·30분·1시간·2시간). 고른 값은 그 PC 브라우저에 기억되고 다음 발급부터 적용된다. 이미 뽑은 이용권의 기한은 바뀌지 않는다. 쪽지에는 '오늘 21:45까지'처럼 만료 시각이 찍힌다. 관리자 화면(`/admin/photobooth#events`)에서 발급한 것은 지금처럼 기한이 없다.
- **틀린 번호 잠금:** 없는 번호가 1분 안에 10번 입력되면, 매장의 모든 부스가 1분간 번호를 받지 않는다. 마스터 번호도 이때는 막힌다. 이미 쓴/취소된/만료된 번호를 다시 넣는 것은 틀린 입력으로 세지 않는다. 입력 기록을 읽지 못하면 잠그지 않는다(손님 흐름 우선).
- **카운터 기기 권한:** 카운터 PC는 관리자 로그인이 아니라 **카운터 PIN**으로 한 번 연결한다(180일 유지). 할 수 있는 일은 이용권 발급·다시 출력·오늘 발급분 취소뿐이다. PIN을 바꾸면 연결된 기기가 모두 풀린다. 관리자 계정으로 로그인한 브라우저에서도 이 화면을 쓸 수 있다.
- **다시 출력·취소:** 용지가 걸렸으면 목록에서 "다시 출력"을 누른다(같은 번호). 잘못 뽑았으면 "취소"를 누른다. 사용한 이용권은 취소되지 않는다.
- 관리자 이용권 목록에 발급처(카운터/관리자)와 기간 만료가 표시된다. 매출 건수와 대조할 수 있다.

## 이용권 QR

- 쪽지마다 번호 아래에 QR(약 27mm)을 찍는다. QR에는 `ACSPASS:<6자리>`만 담는다. 손님이 폰으로 찍으면 글자만 보이고, 권한은 번호를 입력하는 것과 같다.
- 부스 이용권 화면은 왼쪽에 카메라(DSLR 또는 웹캠)와 조준 칸, 오른쪽에 번호 키패드를 둔다. QR이 읽히면 번호 칸이 채워지고 바로 확인한다.
- 인식은 포토카드 스캔과 같은 모듈(`src/lib/photobooth/qr-scan.ts`)을 쓴다. 매장 부스 PC 크롬에는 BarcodeDetector가 없어 jsQR로 읽는다. 전체 화면에서 못 찾으면 가운데(조준 칸 둘레)를 원래 해상도로 한 번 더 읽는다.
- 쓴 이용권을 계속 대고 있으면 같은 번호는 4초에 한 번만 다시 확인한다. 이미 쓴 번호는 틀린 입력 잠금에 세지 않는다.
- 포토카드 QR 등 다른 QR은 이용권 화면에서 무시한다.

## 배포 전 준비 (기기와 무관, 지금 가능)

1. **마이그레이션:** Supabase SQL 에디터에서 `supabase/migrations/20260924_photobooth_counter_passes.sql`을 실행한다. **코드 배포 전에** 실행한다 — 새 이용권 확인 코드가 `expires_at`을 읽기 때문이다. 기존 코드는 새 칸을 무시하므로 먼저 실행해도 안전하다.
2. **환경변수:** Vercel(Production)에 `PHOTOBOOTH_COUNTER_PIN`을 6자리 이상으로 설정한다. 없으면 카운터 기기 연결이 막힌다(관리자 로그인으로만 사용 가능).
3. **마스터 번호 교체 권장:** `PHOTOBOOTH_MASTER_CODE`(기본 110619)가 손님에게 알려지면 통제가 무너진다. 다른 6자리로 바꿔 두는 것을 권한다.
4. 배포 후 관리자 계정으로 `https://www.acscent.co.kr/booth/counter`를 열어 화면이 뜨는지 확인한다.

## 기기 설치 (카운터 전용 윈도우 PC + OKPOS OK30)

카운터 PC는 키오스크·부스 PC와 별개다. 영수증 프린터는 **OKPOS OK30**(실체는 Sewoo LK-T 계열, 한 줄 512점·180dpi·72mm)이다. **제조사 드라이버는 설치하지 않는다.**

- 화면이 쪽지를 직접 그려 프린터 명령(ESC/POS)으로 바꾼다. 쪽지 길이는 내용에 맞추고, 한 장마다 자른다.
- PC의 **인쇄 도우미**(`127.0.0.1:9131`)가 그 바이트를 윈도우 스풀러에 RAW로 넘긴다.
- 프린터 등록에는 윈도우 내장 `Generic / Text Only` 드라이버를 쓴다. 이 드라이버는 이름만 빌린다.

1. **연결:** 프린터 뒷면 **USB 단자(네모난 B형)**에 직접 꽂는다. 9핀 시리얼에 변환 젠더를 쓰면 느리고(9600bps), 데이터가 유실돼 자르기가 안 된다(2026-09-30 확인).
2. **설치:** 이 저장소의 `scripts/counter-pc/` 폴더를 통째로 PC에 복사하고 `INSTALL.cmd`를 더블클릭한다(관리자 권한 요청에 "예"). 스크립트가 차례로 다음을 한다.
   - OK30(USB `VID_0525&PID_A700`)의 USB 포트를 찾아 `ACSCENT-Receipt`로 등록한다.
   - 도우미를 `C:\ACSCENT-Counter`에 두고 부팅 시 자동 실행(SYSTEM, 작업 스케줄러 `ACSCENT_COUNTER_PRINT`)으로 등록한다.
   - 크롬 정책으로 `acscent.co.kr`이 이 PC의 도우미에 접근하도록 허용한다.
   - 바탕화면·시작 프로그램에 "포토부스 이용권 발급" 바로가기를 만든다.
   - 시험 쪽지를 출력한다.
3. **기기 연결:** 바로가기를 열고 카운터 PIN을 입력한다(또는 관리자 로그인).
4. **확인:** "오늘 발급한 이용권" 옆에 **영수증 프린터 연결됨**이 보이는지 확인한다. 이어서 "시험 출력"과 "1장 출력"으로 실제 번호를 뽑아 부스에서 입력해 본다.
   - 크롬이 "이 기기의 다른 앱·서비스에 접근" 허용을 물으면 **허용**한다. 정책이 먹지 않는 크롬 버전 대비다.

**문제가 생기면**

| 표시 | 확인 |
|---|---|
| 인쇄 도우미 없음 · 브라우저 인쇄 | 도우미가 꺼짐 → 작업 스케줄러에서 `ACSCENT_COUNTER_PRINT` 실행, `C:\ACSCENT-Counter\helper.log` 확인. 크롬이 접근을 막았을 수도 있다(주소창 왼쪽 사이트 설정 → 로컬 네트워크 허용). |
| 영수증 프린터 확인 필요 | 프린터 전원·용지·덮개. 인쇄 실패 시 작업은 큐에서 지운다(나중에 한꺼번에 쏟아지지 않게). |
| 프린터 USB를 다른 구멍에 꽂았더니 안 나옴 | USB 포트 번호가 바뀐다 → `INSTALL.cmd`를 다시 실행 |

- 도우미 단독 점검: `powershell -ExecutionPolicy Bypass -File C:\ACSCENT-Counter\counter-print-helper.ps1 -SelfTest`
- 도우미는 `acscent.co.kr`과 localhost·사설 IP에서 연 화면의 인쇄만 받는다.
- 도우미가 없으면 화면이 브라우저 인쇄(쪽지 115mm, `SLIP_HEIGHT_MM`)로 넘어간다. 드라이버를 깐 PC에서는 그 경로로도 쓸 수 있다.

**맥에서 개발·시험:** `sudo tools/receipt-printer-mac/install.sh`를 실행하면 맥 프린터 목록에 OK30이 생긴다(브라우저 인쇄 경로). `node tools/receipt-printer-mac/helper.mjs`는 윈도우 도우미와 같은 계약으로 동작한다.

## 파일

- `supabase/migrations/20260924_photobooth_counter_passes.sql`: `expires_at`, `issued_via`, 틀린 입력 기록 테이블
- `src/lib/photobooth/passes.ts`: 발급·만료 계산 (관리자·카운터 공용)
- `src/lib/photobooth/counter-auth.ts`: 카운터 기기 PIN 연결
- `src/app/api/photobooth/counter/`: 연결(`route.ts`)과 발급·목록·취소(`passes/route.ts`) API
- `src/app/api/photobooth/pass/route.ts`: 부스 번호 확인 (기한·잠금 추가)
- `src/app/booth/counter/`: 카운터 화면과 쪽지 인쇄
- `src/lib/photobooth/counter-slip.ts`: 쪽지 캔버스(QR 포함) → ESC/POS, 인쇄 도우미 호출
- `src/lib/photobooth/qr-scan.ts`: 부스 카메라 QR 인식(카드·이용권 공용), 이용권 QR 형식
- `scripts/counter-pc/`: 윈도우 설치(`INSTALL.cmd`·`install-counter-printer.ps1`)·인쇄 도우미·바로가기
- `tools/receipt-printer-mac/`: 맥 개발용 OK30 드라이버와 도우미
- `node scripts/verify-photobooth-passes.mjs`: 메모리 DB 모형으로 연결·발급·사용·만료·잠금 검증 (운영 데이터 무관)
