# AC'SCENT 상품 이미지 리서치 및 생성 결과

리서치 기준일: 2026-07-18

## 목적

홍대 `악센트 아이디` 매장과 실제 택배 수령 후기에서 확인되는 상품 형태를 우선 근거로 삼아, 사이트의 12개 상품/프로그램에 사용할 수 있는 참고 기반 상품 이미지를 각 5장씩 제작했다.

여기서 "학습"은 별도 모델을 재학습했다는 뜻이 아니다. 수집한 공개 이미지에서 반복적으로 확인되는 보틀, 패키지, 리포트, 구성품, 재질, 크기 관계를 시각 기준으로 정리하고 이미지 생성 때 참조한 방식이다.

## 결과물

- 상품별 이미지: 5장

## 생성 구도

각 상품은 가능한 범위에서 다음 5개 역할을 나눴다.

1. 전체 구성품이 보이는 대표 카탈로그 컷
2. 다른 각도 또는 옵션/규격 컷
3. 택배 개봉 또는 패키지 구성 컷
4. 재질과 구조를 보여주는 근접 컷
5. 손과 함께 보여주는 실제 크기 비교 컷

## 사용 주의

- 생성 결과는 실물 자료를 참조한 **상품 시각화**이며 실제 고객이 촬영한 후기 사진이 아니다.
- 사이트에 사용할 때 `고객 후기`, `실제 구매자 촬영`처럼 오인시키는 문구와 결합하지 않는다.
- 실제 후기 영역에는 원저작자의 사용 허락을 받은 사진만 사용한다. 이 폴더의 네이버 원본은 내부 형태 조사와 검수 근거로만 취급한다.
- `saju`, `personal`, `today-scent`, `scent-paper`처럼 독립적인 실물 후기 근거가 적은 항목은 출시 전 실제 양산품과 다시 대조한다.
- 생성 이미지 속 리포트의 작은 글자는 레이아웃 예시다. 개인 정보, 분석 수치, 향 노트 문구는 실제 데이터와 디자인 파일로 교체해야 한다.
