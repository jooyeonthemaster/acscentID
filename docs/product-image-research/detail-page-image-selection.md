# 배포 상세페이지용 이미지 선별 및 카피 가이드

기준일: 2026-07-18  
대상: 현재 노출 중인 2개 프로그램과 3개 단품 상세페이지  
선정 결과: 최종 사용 권장 23장, 제외 5장

## 기준

- 현재 배포 페이지의 상품명, 가격, 옵션, 포함 구성과 충돌하지 않는 사진만 골랐다.
- 첫 사진은 최저 노출 가격의 구성과 맞추고, 이후 `구성품 -> 패키지 -> 디테일 -> 크기/사용 장면` 순으로 이해되게 배치한다.
- 생성 이미지는 제품 설명용 시각화로만 사용한다. `실제 후기`, `고객 수령 사진` 영역에는 넣지 않는다.
- 고객 후기 사진은 원저작자 사용 동의를 받은 원본만 별도로 사용한다.
- 패키지가 생산 시점에 따라 바뀔 수 있다면 상세 하단에 `패키지 및 인쇄물 디자인은 제작 시점에 따라 일부 달라질 수 있습니다.`를 표시한다.
- 이미지 안에 카피를 다시 합성하지 말고, 아래 멘트를 HTML 텍스트와 이미지 캡션으로 노출한다.

조사 근거는 [제품 사실표](references/analysis/product-facts.md)를 기준으로 했다.

## 적용 우선순위

1. 각 페이지의 첫 번째 이미지를 위 대표 이미지로 교체한다.
2. 갤러리를 표의 순서대로 등록한다.
3. 현재 H1, 가격, 옵션명은 유지하고 `상단 보조문구`와 `구성 안내`를 보강한다.
4. 프로그램 페이지에는 리포트 확대 컷을 결과/특별함 섹션 바로 뒤에 한 번 더 배치한다.
5. 단품 페이지에는 `분석 없이 바로 구매`와 `분석 리포트 미포함` 여부를 구성 영역에서 명확히 구분한다.
