# 이벤트 기간 화면 (키오스크·포토부스)

생일카페 같은 매장 이벤트마다 포스터로 **키오스크·포토부스 배경과 글꼴**을 미리 만들어 두면, 그 기간(한국 시간 날짜)에만 두 기기에 자동으로 적용되고 끝나면 평소 배경·글꼴로 돌아갑니다.

관리 화면: 관리자 → 화면 배경 관리 맨 위 **이벤트 배경** (키오스크 관리 ‘키오스크 화면’ 탭, 포토부스 관리 ‘부스 화면’ 탭에도 같은 화면).

## 흐름

1. **불러오기** — 매일 새벽 4시(한국) 크론(`vercel.json` → `/api/cron/screen-events`, `CRON_SECRET`)과 ‘ERP·노션에서 불러오기’ 버튼이 같은 일을 합니다. 오늘 −1일 ~ +75일 행사.
   - **ACSCENT ERP**(Firestore `events`: `store`·`title`·`startDate`·`endDate`) — 기간의 기준. ERP 보안 규칙상 공개 읽기라 웹 설정값 `ERP_FIREBASE_PROJECT_ID`·`ERP_FIREBASE_API_KEY` 로 REST 조회.
   - **노션** ‘생일 이벤트 관리 › 이벤트 굿즈 관리 › N월 이벤트’(`NOTION_EVENT_GOODS_PAGE_ID`, 기본값 코드에) — 토글 제목 `[와우] 세븐틴 정한 (10.3~10.4) /` 을 읽고, 토글 안 첫 칸 묶음(column_list)의 이미지를 포스터로 가져옵니다. 노션 이미지 주소는 1시간 뒤 만료라 `admin-content/screen-events/<id>/` 로 복사해 둡니다(최대 1600px JPEG). 포스터가 아직 없으면 다음 불러오기 때 다시 봅니다.
   - 같은 매장·시작일(또는 같은 이름·3일 이내)이면 한 행사로 합칩니다. ERP 에 없고 노션에만 있는 행사도 들어옵니다.
   - 기기가 있는 **와우 매장과 ‘공통’** 행사만(`DEVICE_STORE`, `src/lib/screen-events/types.ts`).
   - 이미 만든 배경·글꼴·적용 여부는 그대로 두고 이름·기간만 갱신합니다. ‘직접 추가’한 행사는 건드리지 않습니다.
2. **배경 만들기**(관리자가 누름, 1~2분) — `OPENROUTER_SCREEN_API_KEY`(전용 키, 사이트 분석용 메인 키와 비용 분리)로
   - 분석 1번(`google/gemini-3-flash-preview`): 분위기·밝기·바탕/글자/강조색 + 글꼴 55종 중 추천 3개(이유 포함, 목록 밖 id 는 버림)
   - 이미지 2장(`google/gemini-3-pro-image-preview`, 동시): 키오스크 9:16·부스 16:9 — 포스터는 **색·무늬 참고만**, 사람·글자 없음, 가운데는 비워 창이 올라갈 자리. 1080×1920 / 1920×1080 WebP 로 맞춰 저장.
   - 비용은 OpenRouter 가 알려준 값(USD)을 행사에 누적 기록합니다.
3. **미리보기 → 기간 중 자동 적용** — 카드에서 두 기기 미리보기와 추천 글꼴을 보고 고른 뒤 ‘기간 중 자동 적용’을 켭니다. 켜지 않으면 적용되지 않습니다.

## 기기 관리자 창에서 (우측 하단 → PIN)

관리자 창의 [이벤트 배경] · [포토카드 QR](포토부스만) 버튼 → 화면 전체 관리 창(`src/components/screen/DeviceAdminTools.tsx`, 기존·레트로·맥 공통).

- **이벤트 배경**: 이 매장의 진행 중·다가오는 행사(오늘 ~ 약 두 달). 이 기기 배경·포스터 크게 보기, **지금 바로 적용 / 적용 해제**, 기간 중 자동 적용 켜기·끄기, 추천 글꼴·다른 글꼴, 배경 (다시) 만들기.
- **지금 바로 적용**(`forced_at`): 날짜·자동 적용과 상관없이 가장 우선. 해제하거나 행사 종료일이 지나면 저절로 풀림. 관리자 웹 카드에서도 보이고 해제할 수 있다.
- **포토카드 QR**: 카드 목록, QR 크게 보기(부스 카메라 인식 시험), 켜기·끄기(끈 카드의 QR 은 부스가 인식하지 않음). 카드 등록·삭제는 관리자 웹에서만.
- API: `/api/screen-backgrounds/events`(GET·PATCH), `/events/generate`(POST), `/cards`(GET·PATCH) — 10분짜리 기기 PIN 세션 쿠키가 `/api/screen-backgrounds` 경로에만 실리므로 그 아래에 둔다. 세션이 끝나면 '다시 열어 주세요' 안내.

## 기기에 적용되는 방식

- 기기 API(`GET /api/screen-backgrounds?target=`)가 `live` 로 지금 적용할 이벤트 배경·글꼴을 함께 내려줍니다(`liveOverride()`). 순서: ① 지금 바로 적용(가장 최근에 누른 것) ② 기간 중 자동 적용(겹치면 늦게 시작한 행사).
- 공용 hook `useScreenBackgrounds` 가 `live` 를 평소 선택보다 우선해 `activeBackground`·`settings.font` 로 내보내므로 **기존·레트로·맥 모든 화면 디자인이 따로 고치지 않아도 따라옵니다**. 화면 디자인(기존/레트로/맥)은 바꾸지 않습니다.
- 이벤트 기록은 기기에도 캐시해 두어 인터넷이 끊긴 채 켜져도 기간 중이면 이벤트 화면, 종료일이 지나면 평소 화면입니다.
- 이벤트 기간에 기기 관리자 패널에서 배경을 골라도 화면은 이벤트 배경이 우선입니다(평소 선택은 저장되어 끝난 뒤 적용).
- 이벤트 저장소를 못 읽어도 평소 배경은 그대로 나갑니다.

## 저장

비공개 버킷 `screen-background-settings/events-v1/<id>.json` — 행사 하나에 파일 하나(배경 설정과 같은 eTag 캐시 회피). 만든 배경은 배경 라이브러리에 넣지 않고 행사 안에 둡니다(기기 선택 목록을 어지럽히지 않게). id: ERP `erp-…`, 노션 전용 `nt-…`, 직접 추가 `man-…`.

## 검증

`node scripts/verify-screen-events.mjs` — 노션 제목 읽기(연도 추정·해 넘김), 기간·승인·매장·겹침 규칙, 한국 시간 날짜.
