# 키오스크 체험 모드 7종 (2026-10-12)

네일 · 명함 · 스킨케어 · 캐리커처 · 보이스 · 미래 직업 탐색 · 버추얼 메이크업. 목업(`Kiosk-New-Modes-20261012`)을 실제로 도는 운영 모드로 옮긴 것이다. 향 분석(매장·사주)·컬러·타로와 달리 **기존 화면 셸(기존·레트로·맥)을 쓰지 않고 전용 화면 묶음 하나**(`src/app/kiosk/experience`)로 돈다.

- 고르는 곳: 관리자 설정 → **운영 모드** 탭 아래쪽 '체험 모드'(`docs/kiosk-admin.md`). 저장하면 관리자 창을 닫는 순간(또는 손님이 없는 첫 화면에서) 새로고침해 그 모드로 갈아탄다.
- 미리보기: 주소에 `?mode=studio-nail` 처럼 붙이면 기기 설정을 건드리지 않고 그 모드로 본다(`card`·`skin`·`draw`·`voice`·`career`·`makeup`).
- 화면 디자인·글꼴·평소 배경·행사 배경 설정은 이 모드들에서 쓰이지 않는다(관리자 창이 '전용 디자인 사용 중'으로 알린다).
- 영수증·발권 번호·기록(`/api/kiosk/record`)은 없다. 결과는 손님이 **휴대폰으로 받기**를 눌렀을 때만 올라간다.

## 목업에서 정한 선(지킨 것)

- **스킨케어**는 자가 체크로 루틴을 정리하는 안내다. 사진을 찍지 않고, 질병·피부 나이·수치를 말하지 않는다.
- **직업 탐색**은 관심사 기반 탐색이다. 얼굴·음성·성별로 능력을 추정하거나 미래를 단정하지 않는다(결과는 '탐색해 볼 직업 예시').
- **보이스**는 손님 본인의 녹음에 스타일(높낮이·음색·울림)만 입힌다. 다른 사람의 목소리를 흉내 내거나 합성하지 않는다.
- **명함**은 디지털 결과물이다. 명함 프린터·주문·결제가 없다.
- 브랜드 이름·로고는 넣지 않았다. 글자·버튼·입력란은 모두 실제 부품이다(목업 이미지에서는 첫 화면 그림·스타일 견본만 잘라 썼다 — `public/assets/kiosk-experiences`).

## 모드별 동작

### 네일 (`nail/engine.ts`)
손 특징점 21개(MediaPipe HandLandmarker, `public/models/hand_landmarker.task`)에서 손가락마다 손톱 자리·방향·크기를 계산하고, 배경과 구분되는 사진에서는 손가락 윤곽을 읽어 폭·끝을 다듬는다. 손톱 모양의 색 층만 올리고 원본의 명암을 다시 곱해 입체를 남긴다. 손 찾기는 같은 사진도 크기·기울기에 따라 놓칠 수 있어, 못 찾으면 줄이거나 ±14° 돌려 다시 본다. 굽은 손가락은 건너뛰고, 손톱이 3개 미만이면 다시 찍게 한다. 손바닥으로 보이면 막지 않고 '손등으로 찍으면 더 잘 어울려요'만 알린다. 자동으로 잡은 크기가 안 맞으면 손님이 '손톱 크기 − +'로 고친다.

### 메이크업 (`makeup/engine.ts`)
얼굴 특징점 478개(FaceLandmarker, 컬러 모드와 같은 모델)에서 입술·볼·눈두덩 자리를 찾아 색 층만 겹친다(색 + 곱하기 두 번). 얼굴 모양·피부는 건드리지 않는다. 가운데 선을 밀어 원본과 비교한다.

### 보이스 (`voice/audio.ts`)
`MediaRecorder` 로 녹음 → 24kHz 한 채널로 풀어 앞뒤 빈 소리를 자르고 음량을 맞춘다. 스타일은 Web Audio 로 기기 안에서 만든다: **라디오** −1.8 반음 + 저음·또렷함 + 압축, **로봇** 54Hz 링 모듈레이션 + 짧은 되울림, **동화** +4 반음 + 밝은 울림. 높낮이는 겹쳐 잇기(WSOLA)로 길이를 지킨 채 바꾼다. 너무 짧거나(1초 미만) 소리가 거의 없으면 다시 녹음하게 한다. 마이크를 못 찾으면 안내를 띄우고 3초마다 다시 본다.

### 캐리커처 (`src/lib/kiosk/caricature.ts`)
OpenRouter 이미지 모델(기본 `google/gemini-2.5-flash-image`, 장당 약 $0.04·9초)로 그린다. 실패하면 `OPENROUTER_IMAGE_MODEL` 로 한 번 더. 프롬프트는 닮음 유지·친절한 톤·글자 금지를 고정으로 두고 스타일·과장 정도만 바꾼다. 사진과 결과는 서버에 남기지 않는다.

| 환경 변수 | 뜻 |
|---|---|
| `OPENROUTER_KIOSK_IMAGE_API_KEY` | 캐리커처 전용 키(비용을 따로 보고 싶을 때). 없으면 `OPENROUTER_API_KEY` |
| `OPENROUTER_CARICATURE_MODEL` | 모델 바꾸기 |
| `KIOSK_CARICATURE_DAILY_LIMIT` | 서버 인스턴스당 하루 생성 상한(기본 300). 분당 6회 제한도 있다 |

### 명함 (`card/design.ts`)
템플릿 3(미니멀·에디토리얼·블록) × 서체 2 × 색 4 × 정렬. 캔버스로 앞·뒤를 그리고, 인쇄용 PDF(90×50mm 두 쪽)는 라이브러리 없이 직접 쓴다.

### 스킨케어 · 직업 탐색 (`skin/routine.ts`, `career/data.ts`)
규칙 표로 결과를 만든다(AI 호출 없음). 같은 답이면 같은 결과.

## 휴대폰으로 받기 (`src/lib/kiosk/share.ts`, `share-store.ts`)

`POST /api/kiosk/share` → 토큰(생성 시각 8자 + 무작위 20자) → QR → `/kiosk/get/[token]`. 파일은 한 번에 4개·합계 3MB 까지(JPG·PNG·WAV·PDF), 머리 바이트로 형식을 확인한다. 24시간이 지나면 페이지·파일 주소를 막고, 파일은 다음 업로드 때 지운다.

**저장소 버킷(`analysis-images`)은 그림 형식만 받는다.** 그림은 그대로 올리고, 그 밖의 것(WAV·PDF·파일 목록)은 1×1 PNG 의 사설 청크(`kxDt`)에 담아 `이름.png` 로 올린다(`my-voice.wav.png`, `meta.json.png`). 내려줄 때 청크를 풀어 원래 형식으로 준다. 버킷 설정을 바꿀 필요가 없다.

## 배포 전에 · 운영 메모

- 서버 환경 변수는 기존 것만으로 돈다(`KIOSK_ENABLED`·`KIOSK_ALLOW_REMOTE`, `OPENROUTER_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`).
- **보이스**: 매장 키오스크(Windows POS)는 웹캠(ABKO APC930) 내장 마이크가 잡혀 있고, 셸이 `media` 권한(카메라·마이크)을 허용한다(2026-10-12 원격 확인). **스피커가 실제로 소리를 내는지는 매장에서 확인**해야 한다 — 출력 장치는 '헤드폰(High Definition Audio)' 하나만 잡힌다.
- **네일·메이크업**: 인식 엔진(WASM 약 9MB)과 모델(손 7.8MB · 얼굴 3.8MB)은 손님이 없는 첫 화면에서 조각으로 받아 기기 보관함에 둔다. 모드를 처음 켠 직후 첫 손님은 촬영 뒤 준비에 시간이 더 걸릴 수 있다.
- **캐리커처**는 누를 때마다 비용이 든다. 행사에서 오래 켜 둘 때는 OpenRouter 사용량을 본다.
- 키오스크 앱은 자동으로 새로고침하지 않는다 — 배포 뒤 앱을 다시 켜야 새 화면이 뜬다.

## 한계

- 네일은 손톱을 '찾는' 것이 아니라 손가락 뼈대에서 '계산'한다. 손이 작게 찍히거나 배경이 살색이면 자리·크기가 어긋날 수 있다(그래서 크기 조절을 뒀다). 엄지는 옆으로 돌아 있어 가장 덜 맞는다.
- 보이스의 '로봇'은 링 모듈레이션이라 말소리가 다소 알아듣기 어려워진다(의도한 효과).
- 캐리커처 상한(분당·하루)은 서버 인스턴스 안에서만 센다 — 인스턴스가 여럿이면 느슨하다.
- 체험 모드에는 행사 배경·글꼴이 적용되지 않는다.
