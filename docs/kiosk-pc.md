# 노트북 가로 화면 체험 (2026-10-28)

행사에서 노트북을 열어 두고 손님이 직접 쓰는 링크. 세로 키오스크(1080×1920)와 같은 프로그램을 **가로 두 칸**(왼쪽 카메라·사진·그림 / 오른쪽 제목·설명·버튼)으로 보여 준다. 프로그램마다 링크가 따로다.

| 링크 | 프로그램 | 화면 |
|---|---|---|
| `/kiosk/pc/color` | AI 퍼스널 컬러 (`ai-color`) | 기존(classic) 셸 + Chromatic Archive |
| `/kiosk/pc/caricature` | AI 캐리커처 (`studio-draw`) | 체험 화면 틀 |
| `/kiosk/pc/career` | AI 미래 직업 탐색 (`studio-career`) | 체험 화면 틀 |

목록은 `src/lib/kiosk/pc.ts`, 페이지는 `src/app/kiosk/pc/[program]/page.tsx` → `PcScreen.tsx`.

## 키오스크와 다른 점

- **링크가 프로그램을 정한다.** 기기 설정(운영 모드·체험 모드·화면 디자인)을 읽어 화면을 갈아타지 않는다(`KioskClassic` 의 `pinnedMode`, `ExperienceApp` 의 `pc`). 우측 상단 관리자 창이 없다.
- **워터마크 없음** — `KioskWatermark` 를 싣지 않는다(행사 운영용).
- **영수증 대신 휴대폰 QR.** 노트북에는 감열 프린터가 없어 결과 화면의 영수증 버튼을 빼고 [휴대폰으로 받기]를 크게 둔다. QR → `/kiosk/get/[token]` 에서 저장(24시간 보관, `docs/kiosk-experiences.md` '휴대폰으로 받기').
  - 퍼스널 컬러는 원래 영수증만 있었다 — 결과 카드(유형·잘 어울리는 색 8·피할 색 4·톤 눈금·스타일 가이드·키워드, 1080 폭 JPG)를 새로 그려 올린다(`pc/color-card.ts`, `pc/ColorShareSheet.tsx`). **손님 사진은 넣지 않는다**(퍼스널 컬러 사진은 진단에만 쓴다는 원칙). 받기 종류 `color` 를 더했다(`share.ts` 의 `SHARE_KINDS`, 받기 페이지 머리 'COLOR!').
  - 직업 탐색의 저장 그림에 **AI 분석 풀이**를 넣었다(키오스크도 같이 — 그 전에는 화면에만 있고 받는 그림에는 빠져 있었다).
- **이름은 노트북 자판으로** — 퍼스널 컬러 이름 칸이 터치 키보드 대신 실제 입력 칸이다(한글 입력기 그대로, Enter 로 다음).
- **옷 색 미리보기 파일을 쉬지 않고 받는다** — 매장 키오스크는 USB Wi-Fi 동글 때문에 320KB 조각을 1.3초 간격으로(2~4분) 받지만, 노트북은 4MB 조각을 쉬지 않고 받는다(`setGarmentDownloadFast`). 손님이 시작하면 멈추는 것은 같다 — 첫 손님이 너무 빨리 오면 그 손님은 드레이프(얼굴 둘레 색)를 본다.
- 결과 QR 을 찍는 동안 무입력 시간을 150초로 늘린다. 분석 기록(`/api/kiosk/record`)의 `device` 는 `pc`.

## 화면 맞추기

화면은 **1280×780 CSS 픽셀** 기준으로 그리고 창 크기에 맞춰 통째로 키우거나 줄인다(`pc/usePcFit.ts`, CSS `zoom` — 세로 키오스크가 560 폭으로 그리고 셸이 1.93배로 키우는 것과 같은 방식). 높이가 모자라면 높이에 맞춘다(그만큼 가로가 넓어진다). 노트북 배율(125%·150%)·브라우저 머리 높이가 달라도 글자·버튼 비율이 같다. 전체 화면(F11)으로 쓰면 가장 크게 보인다.

- 배치 CSS: `experience/experience-pc.css`(캐리커처·직업 탐색), `pc/color-pc.css`(퍼스널 컬러). 모두 `[data-layout='pc']` 아래라 매장 키오스크 화면에는 영향이 없다.
- 오른쪽 칸은 그리드 맨 위 빈 줄(`::before`)과 맨 아래 `1fr` 줄이 남는 높이를 나눠 세로 가운데에 온다. 왼쪽 그림 하나가 모든 줄을 차지한다.
- 퍼스널 컬러 결과: 왼쪽 옷 색 미리보기는 붙박이, 오른쪽(유형·색·톤·스타일)만 스크롤(`ColorReportView` 의 `pc`). 직업 탐색 결과: 왼쪽 풀이(제목·AI 분석·단서), 오른쪽 직업 셋·첫 도전·받기(`CareerMode` 의 `crr-pc-cols`).
- 직업 탐색 질문은 두 칸이 아니라 가로로 넓게 — 활동 4열, MBTI 8열, 답 셋 나란히.

## 확인한 것 (2026-10-28, 로컬 개발 서버 · 헤드리스 크롬 가짜 카메라)

- 1280×600 · 1440×820 · 1536×730 · 1920×970 에서 세 프로그램의 모든 단계(첫 화면 → 입력 → 촬영 → 분석 대기 → 결과 → QR 창), 캐리커처 '같이'(가로 사진), 퍼스널 컬러 옷 색 미리보기·나란히 비교. 화면 밖으로 넘치는 요소 없음.
- 실제 올리기 → QR 을 읽어 휴대폰 크기(390×844)로 받기 페이지 → 파일 내려받기(200, image/jpeg) — 퍼스널 컬러·직업 탐색.
- 매장 키오스크 세로 화면(`/kiosk?mode=…`, 560×996)은 그대로 — 터치 키보드·영수증 버튼·결과 배치.
- AI 분석·그림 생성은 가로챈 응답으로 봤다(퍼스널 컬러는 서버 데모 응답). 실제 노트북 웹캠·행사장 망에서는 아직 안 봤다.

## 행사 전에

- 노트북 브라우저에서 카메라 권한을 허용해 둔다(처음 열 때 한 번 묻는다). 웹캠이 없거나 막히면 퍼스널 컬러는 '사진 파일로'·'QR로 폰 사진 올리기'가 남는다.
- 캐리커처는 한 장마다 생성 비용(약 $0.04)이 든다 — 사진 한 장에 세 장까지.
- 퍼스널 컬러 링크를 연 채로 2~3분 두면 옷 색 미리보기 파일이 다 받아진다(그 뒤로는 브라우저 보관함에 남는다).
