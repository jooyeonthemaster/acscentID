# 키오스크 현장 관리자 창

고객 화면 우측 상단 모서리(짧게 누르거나 1.5초 누르기) → 6자리 비밀번호 → **관리자 설정**. `/admin` 웹과는 별개의, 매장 직원이 기기 앞에서 쓰는 창이다.
2026-10-10 에 한 화면에 쌓여 있던 설정을 작업별 탭으로 나눴다(목업: `Kiosk-Admin-Redesign-20261010`).

- 코드: `src/components/kiosk-admin/` — `KioskAdminPanel.tsx`(인증·홈·운영 모드·화면·글꼴·평소 배경·앱 종료), `AdminEvents.tsx`(행사 배경), `AdminFontPicker.tsx`(글꼴 고르기), `admin-ui.tsx`(알림 띠·창 안의 창·Escape 순서·포커스), `kiosk-admin.css`.
- 기존·레트로·맥 셸이 같은 창을 쓴다(`KioskClassic.tsx` · `KioskClient.tsx` 는 열고 닫기만 한다). `document.body` 에 띄우므로 고객 화면의 테마(컬러·타로 포함)·zoom 과 상관없이 늘 같은 모양이다.
- 포토부스 관리자 창은 그대로다(`DeviceDesignControls` · `DeviceAdminTools` · `BoothModeControls`).

## 탭

| 탭 | 하는 일 | 저장 범위 |
|---|---|---|
| 홈 | 지금 운영 모드·실제 화면 디자인·행사 적용 상태, 각 탭으로 가는 카드 | — |
| 운영 모드 | 매장 기본 / K-WAVE 사주 / AI 퍼스널 컬러 / AI 타로. 사주 모드일 때만 한자 글꼴·영수증 양식 | 같은 종류의 키오스크 모두(`settings-kiosk`) |
| 화면·글꼴 | 기존/레트로/맥 디자인, 화면 글꼴 | 같은 종류의 키오스크 모두 |
| 평소 배경 | 행사가 없을 때의 배경(추천 글꼴이 있으면 글꼴도 함께) | 같은 종류의 키오스크 모두 |
| 행사 배경 | 진행 중·다가오는 행사 → 상세(지금 바로 적용, 기간 중 자동 적용, 행사 글꼴, 배경 만들기) | **행사 공통** — 포토부스에도 반영 |

관리자 이름(매장 기본·K-WAVE 사주…)은 `KioskAdminPanel.tsx` 의 `MODE_COPY` 에 있다. 새 모드를 `modes.ts` 에 더하면 목록에는 바로 나오고(모드의 `label`·`note` 사용), 짧은 이름을 붙이려면 `MODE_COPY` 에 한 줄을 더한다.

## 지켜야 하는 동작

- **고르는 즉시 저장**한다. 전체 저장/취소 단계가 없고, 창을 닫아도 저장한 것은 되돌아가지 않는다.
- 운영 모드는 **다음 손님부터** 적용된다.
- 전용 배경이 있는 모드(K-WAVE)는 모드와 배경을 **두 번 저장**한다. 배경만 실패하면 '모드는 저장됐지만 전용 배경은 바꾸지 못했어요'로 알리고 배경만 다시 적용하게 한다 — 전체 실패로 보이거나 모드를 되돌리지 않는다.
- 화면 디자인을 바꾸면 저장 뒤 **페이지가 새로 열린다**(`useScreenUiSwitch`) — 고객 시작 화면으로 돌아가고 관리자 창도 닫힌다. 저장하는 동안은 닫을 수 없는 전환 안내가 뜬다.
- 컬러·타로 모드는 전용 디자인을 쓴다. 일반 디자인·글꼴·평소 배경은 그 모드에서도 고치고 저장할 수 있지만 **매장·사주 모드에서 보인다**(탭마다 안내).
- 행사 글꼴이 우선 적용 중이면 '평소 선택한 글꼴'과 '지금 적용된 글꼴'을 따로 보여준다.
- **지금 바로 적용(수동)** 과 **기간 중 자동 적용**은 서로 다른 상태다. 수동을 해제해도 행사 기간이고 자동 적용이 켜져 있으면 같은 배경이 계속 보인다. 자동 적용을 꺼도 수동 적용은 풀리지 않는다. 해제 뒤 '평소 배경으로 돌아간다'고 단정하지 않는다.
- 배경 만들기는 유료다 — 비용(약 400원)·시간(30초~1분)·2장 생성을 확인받고 시작한다. 진행률·취소·환불은 없다(생성 중에는 창을 닫을 수 없다). 이미 적용 중인 행사를 다시 만들면 새 배경이 바로 화면에 나갈 수 있음을 확인창에서 알린다. 실패 뒤 다시 시도하면 확인 단계부터 다시 거친다.
- 앱 종료는 앱만 끈다(PC 종료·재시작이 아니다). 브라우저에서는 종료할 수 없다고 알린다.

## 인증

- 서버 인증(`POST /api/screen-backgrounds/unlock`) 후 10분. 6자리째 자동으로 확인하고, 확인 중에는 모든 키가 잠긴다(취소 가능 — 늦게 온 결과는 버린다).
- 틀리면 오류와 함께 입력을 비운다. 너무 많이 틀리면(429) 1분간 키패드를 잠근다.
- 서버에 닿지 못하면 기기(셸 `checkAdminPin`)가 비밀번호를 확인해 **앱 종료만** 연다. 그 기능이 없는 셸이면 연결 오류를 보여준다.
- 인증 시간이 끝난 뒤 저장하거나 행사를 읽으면(403) '관리자 인증이 필요해요' 화면 → 다시 인증하면 보던 탭으로 돌아온다. 그때 누른 설정은 저장되지 않았으므로 다시 눌러야 한다.
- `useScreenBackgrounds` 의 저장 오류에는 `status` 가 실려 온다(403 만료 · 409 없어진 배경 · 429 입력 제한).

## Escape · 창 밖 누르기

맨 위 창부터 하나씩 닫는다(`useAdminLayerRoot`): 글꼴 고르기·크게 보기·확인창 → 행사 상세(→ 목록) → 관리자 창. 닫을 수 없는 창(배경 생성 중·화면 디자인 전환 중)이 떠 있으면 아무 일도 일어나지 않는다.

## 검증

실제 설정을 건드리지 않고 확인하려면 브라우저에서 `/api/screen-backgrounds*` 요청을 모두 가로채 가짜 응답을 준다(로컬 서버도 운영 DB 를 본다). 2026-10-10 에는 매핑표의 38개 동작을 이 방식으로 눌러 확인했다 — 화면 캡처는 `design-review/kiosk-admin-redesign-20261010/`.
