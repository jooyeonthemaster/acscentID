## 1. 상품 정체성 ✅

### 1.1 퍼널 구조 — 두 세계의 역할 분리
- **온라인 분석 경험** = 자정의 조향소, 먹색/금박/명리. 프리미엄 신비. **무료 후킹.**
- **손에 쥐는 상품** = 태극+오행을 새긴 **세련된 명리 키링 디퓨저.** 제품 자체가 프리미엄 신비를 체현(kawaii 아님). 진입가는 낮게. **진입 구매.**
- **업셀** = 향수(10/50ml) · 궁합 2p 세트 · 최애 프리미엄 기프트박스.
- 브릿지 서사: "심오하게 짚어준 당신의 부족한 기운(用神)을, 가방에 매달고 다니는 향으로." 심오함 → 일상 휴대.

### 1.2 제품 폼 ✅ (실물 시제품 확정 — `saju-actual-product-sample/`)
- **본체(통일)**: 짙은 남색 먹색 + 메탈릭 펄. 한쪽 끝 = **원형(태극/음양)**, 반대쪽 끝 = **오각형(오행 버튼)**. 프리즘형 소형 키링.
- **향 방출**: 본체 **중앙 측면의 벤트 구멍(콧구멍형)**에서.
- **클릭**: **양쪽 다** 클릭됨(태극 원형 + 오각). 피젯 요소.
- **커스터마이징**: 상단 오각 버튼 = 사주 추천 오행으로 결정. **주문 시 선택 → 조립 고정 출고**(사용자 교체 불가).
- **제조 효율**: 본체·태극 금형 통일 1종 + 오각 버튼 4종만 별도. 재고·툴링 최소.
- 캐릭터/신캐릭터 개념 **폐기** — 이건 명리 오브제(부적/인장 결)이지 마스코트가 아님.

### 1.3 오행 4버튼 시스템 ✅ 핵심 메커니즘
용신(부족한 기운) 오행이 **어느 오각 버튼을 얹을지 결정**. 실물 확정 = **금·화·수·토 4종**(목 제외, 빨간 화·노란 토 폐기).

| 오행 | 버튼 색 | 아이콘 |
|---|---|---|
| 금(金) | 은색 | 결정(크리스탈) |
| 화(火) | 분홍 | 물방울/퍼지는 동심원 |
| 수(水) | 하늘색 | 물결(세이가이하) |
| 토(土) | 브라운 | 격자·벽돌 |

- 공유 훅: "내 오행 버튼 뭐 나왔어?" → 결과 공유. 궁합 = 두 사람 버튼 조합.
- 시간 모름(삼주)·용신 동률: 엔진이 조후 타이브레이크로 단일 용신 확정([chart.ts](../../src/lib/saju/chart.ts)).
- ✅ **목(木) 용신 → 수(水) 버튼** (수생목: 물이 나무를 낳는 근원). 서사: "당신에게 부족한 목(木)의 기운은, 그것을 낳는 수(水)로부터 길어 올립니다." 향(scent-map)은 목 계열 노트로 별도 보완 가능.
- 최종 매핑: 목·수→**수 버튼**, 화→화, 토→토, 금→금. [scent-map.ts](../../src/lib/saju/scent-map.ts) 옆에 **용신→버튼** 테이블 추가.

## 2. SKU 라인업 & 가격 🟡 (숫자는 제안 — MOQ/원가 확인 후 확정)

### 2.1 아키텍처 판단 ✅ — 새 product_type 안 만든다
`saju_perfume` 하나 유지, **`size` 옵션으로 라인업 구성**. `admin_product_pricing`은 `(product_type, size)` 키라 size 추가는 무비용. DESIGN.md §6 통합 체크리스트(레지스트리/네비/i18n/관리자/인쇄 등)는 product_type 단위 → **추가 통합 작업 0.** 궁합 세트도 partner 데이터가 이미 `analysis_data` 안에 있어 별도 product_type 불필요(chemistry_set과 달리 `layering_session_id` 안 씀).

### 2.2 가격 사다리 (진입 저가 + 업셀)

| size 키 | 상품명 | 구성 | 향 전달 | 제안가 |
|---|---|---|---|---|
| `clicker` | 사주 클리커 디퓨저 (밀봉) | 용신 오행 버튼 조립 완제품 1 + 향 밀봉 | 밀봉형 | **₩19,000** |
| `clicker_refill` | 사주 클리커 디퓨저 (리필) | 완제품 1 + 리필 향 패드/오일 1 | 리필형 | ₩26,000 |
| `refill` | 리필 향 (소모품) | 향 패드/오일 리필 1 | — | ₩9,000 |
| `10ml` | 운명의 향 퍼퓸 10ml | 추천 향수 | — | ₩29,000 |
| `50ml` | 운명의 향 퍼퓸 50ml | 추천 향수 | — | ₩48,000 (기존 시드가) |
| `set_couple` | 궁합 2인 세트 | 두 사람 용신 버튼 완제품 2 + 각자 향 | 밀봉형 | ₩34,000 |
| `giftbox` | 최애 프리미엄 기프트박스 | 완제품 + 명식 카드 + 처방전 두루마리 + 금박 봉인(+옵션 10ml) | 밀봉형 | ₩39,000~49,000 |

- **밀봉형 = 진입 저가**, **리필형 = 재구매(LTV) 엔진**, **`refill` 소모품 = 반복 매출.** ✅ 사용자 선택 반영.
- 배송비: 소계 5만원 이상 무료 / 미만 ₩3,000([pricing.ts](../../src/lib/products/pricing.ts) 정책). 진입 ₩19,000 → 배송비가 **향수/세트 끼워담기(장바구니 상향)** 넛지로 작동.
- 할인 표기: `original_price` 컬럼으로 런칭가/정가 연출 가능.
- 주문 시점 `unit_price` 스냅샷 → 이후 가격 변경 무영향(기존 계약).

### 2.3 관리자 노출 ✅
- `admin_products` 사주 상품 `is_active=false` 시드 존재 → 관리자가 켜기 전 비공개([20260707_saju_program.sql](../../supabase/migrations/20260707_saju_program.sql)). `?adminPreview=1`로 사전 검수.
- 각 size 행을 `admin_product_pricing`에 시드(마이그레이션 1건 추가) + `is_active` 개별 토글.

## 3. 상품 상세 / 구매 페이지 🟡

### 3.1 진입 경로
- **주 경로**: `/result?type=saju` 終章(향 공개) → 하단 고정 액션 바 "이 향을 담다" CTA → 구매 옵션 시트.
- **보조 경로**: `/programs/saju` 랜딩 + `/products/saju` 카탈로그 상세(비분석 진입자용 — 단, 분석 없이는 용신 색 미확정 → "먼저 분석하기" 유도).

### 3.2 구매 옵션 시트 (결과 페이지에서 호출)
- **용신 컬러 프리뷰**: 내 분석 결과의 용신 색으로 캐릭터를 미리 렌더(오행색 = 이미 result에 있음). "당신의 색: 금(金) 백금".
- **size 사다리 선택**: 밀봉 클리커(기본 선택) → 리필 → 10ml → 50ml → 궁합 세트 → 기프트박스. 각 옵션 가격·구성 1줄.
- **궁합 세트**: 목적=compatibility 결과일 때만 노출(파트너 용신 색도 함께 프리뷰).
- **최애 기프트박스**: targetType=idol일 때 상단 추천 배치(팬덤 객단가).
- 수량 조절 + 장바구니/바로구매(기존 [checkout](../../src/app/[locale]/checkout/page.tsx) 흐름 재사용, `validateServerPrice('saju_perfume', size, price)`).

### 3.3 재사용 자산
- 상세 UI 문법: [products/[slug]/page.tsx](../../src/app/[locale]/products/[slug]/page.tsx)의 `UnifiedDetailHero` + sticky footer 패턴.
- 결과→장바구니: `POST /api/cart` (`product_type: 'saju_perfume'`, `analysis_id` 필수, size, analysis_data에 sajuChart/추천향 스냅샷).
- 스킨: 사주 팔레트(먹색/금박/한지) — 기존 스토어 톤과 분리된 사주 전용 스킨.

## 4. 패키지 · 언박싱 🟡 (레퍼런스 = 포장 방식만 차용)

### 4.1 포장 폼 (레퍼런스 계승)
- **투명 PET 롱박스** — 키링 디바이스 실루엣이 보이는 세로 박스.
- **상단 원형 스티커**: 오리+잎 → **낙관(印) + 오행/태극 모티프**로 교체. 문구 "運命調香" / "命香 CLICKER". 먹색 배경 + 금박. (프롬프트 3안 별도 작성됨)
- **하단 밴드 라벨**: 마룬 → **먹색 + 금박** "AC'SCENT ID · 運命調香" + 상품명. **밴드/스티커 포인트 색을 용신 오행색과 연동**(4종 시각 구분).

### 4.2 동봉물 (프리미엄 근거 = 디지털 서사의 실물화)
- **미니 명식 카드**(신용카드 사이즈): 4주 8자 격자 + 오행 색 도트 + 용신 낙관. (인쇄 보고서 좌측 블록의 축약 — [DESIGN.md §5](./DESIGN.md) 자산 재활용)
- **처방전 미니 리플릿**: "뿌리는 시간/계절" 리츄얼 가이드 1장.
- **기프트박스 등급**: 처방전을 **두루마리 + 금박 봉인**으로 격상 + 최애 이름/명식 각인.

### 4.3 오행 컬러 시스템
- 오각 버튼 · 밴드 라벨 · 스티커 포인트 = 용신 오행색 연동. 4종이 진열대에서 컬렉션처럼 보이게(은/분홍/하늘/브라운).

## 5. 프로모션 · 런칭 🟡

### 5.1 단계
- **P0 소프트**: `is_active=false` 유지, `?adminPreview=1` 내부 검수 + 실물 샘플 승인.
- **P1 온라인 런칭**: 무료 사주 분석 → 결과 공유([ShareCard](../../src/app/[locale]/result/components/ShareCard.tsx)에 용신 오행 버튼) → "내 오행 뭐 나왔어?" 밈 → 진입 저가 클리커 구매. **실물 생산 리드타임이 병목이면 pre-order(예약구매)로 선오픈.**
- **P2 팬덤**: 최애 모드 → 기프트박스. 컴백/생일 시즌 타겟, 최애 이름 각인.
- **P3 오프라인**: 팝업/전시 QR(offline mode 기구현) + 개인결제링크([payment-links](../../src/lib/payment-links/))로 현장 판매·예약. 4종 진열 = 수집 유발.

### 5.2 성장 훅
- **컬렉션**: 오행 4종 컴플리트, 궁합 커플 2종 조합, 시즌 한정.
- **재구매**: `refill` 소모품 + 리필형.
- **바이럴**: 용신 오행 공유 카드, 궁합 결과 커플 공유.
- **번들 넛지**: ₩19,000 진입 + ₩3,000 배송비 → 5만원 무료배송 라인까지 향수/세트 끼워담기.

## 6. 기술 연결 (구현 시 — 요약)

- **product_type**: `saju_perfume` 재사용(신규 생성 안 함). ✅
- **size 유니온 확장**: `cart.ts` PRODUCT_PRICING[`saju_perfume`]에 `clicker`/`clicker_refill`/`refill`/`10ml`/`50ml`/`set_couple`/`giftbox` 추가.
- **마이그레이션 1건**: `admin_product_pricing` size 행 시드 + (필요시) size 화이트리스트 CHECK 확장.
- **용신→버튼 매핑**: `scent-map.ts` 옆에 용신 오행→오각 버튼(금/화/수/토) 테이블 추가. 주문 시 선택 버튼을 `analysis_data`(또는 order_items)에 기록 → 조립 SKU로 출고.
- **결과 페이지**: 終章 CTA → 구매 옵션 시트 컴포넌트 신규(saju 스킨). 내 용신 오행 버튼 프리뷰.
- **재고**: 오프라인 재고 차감은 `matchingPerfumes[0]` 코어 유지로 기존 fragrance-usage 호환(DESIGN.md §2.3).
- **인쇄/동봉물**: 미니 명식 카드는 PrintableReport `saju_perfume` 자산에서 파생.

## 7. 오픈 이슈 · 가정 ⬜ (확정 전 검증 필요)

1. ✅ **목(木) 용신 매핑 확정**: 목→**수(水) 버튼**(수생목). §1.3 반영 완료.
2. **향 전달 메커니즘**: 본체 중앙 벤트 방출. 밀봉형 향 잔존 기간, 리필 방식(오일 점적 vs 패드 교체) 실물 검증.
3. **실물 생산**: 본체·태극 통일 금형 1종 + 오각 버튼 4종. MOQ·개당 원가 → **공장 확인 후 가격 확정.**
4. **가격**: §2.2 숫자는 전부 제안 — 원가/MOQ 나오면 재산정.
5. **상품 작명**: 「命香」계열 등 §1.1 — 별도 확정.
6. **배송 파손**: PET 롱박스 완충 포장 검토. **명식 카드 개인정보**: 생년월일 각인물 취급.
