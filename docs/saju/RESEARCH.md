# 사주 엔진·매핑 리서치 결론 (검증 완료분 요약)

> 2026-07-07, 실측 검증 기반. 원문 dossier의 핵심만 보존. 구현 판단의 근거 문서.

## 1. 계산 엔진 결론

- **일진 공식**: `(JDN + 49) mod 60` (0=갑자). 앵커 검증: 2000-01-01=무오, 1990-02-04=경자, 1995-08-15=무인 (전체 사주 乙亥 甲申 戊寅 甲寅, 04:30생).
- **년주/월주 경계 = 절기 절입 시각** (년=입춘, 월=12절). 1990 입춘 = 02-04 **11:14 KST** — 10:30생은 기사년 정축월 / 11:30생은 경오년 무인월 (경계 실증).
- **주 엔진: npm `manseryeok` v2.0.0** (MIT, 2026-06 갱신, 127KB, DB 불필요) — KASI 분 단위 절기(1800–2300), 음양력(1391–2100, 윤달), `trueSolarTime`(경도+균시차+서머타임 IANA), `dayBoundary: 'midnight'|'jasi'|'splitJasi'`, 십신·대운 반환. 신생 패키지(스타 29)이므로 자체 회귀 셀프테스트 필수.
- **주의: `lunar-javascript`(6tail)의 절기 시각은 북경시(UTC+8)** — KST 입력 시 1시간 오차. 교차검증 용도로만, 입력 KST−1h 변환 후 사용.
- `korean-lunar-calendar`는 세차/월건이 설날·음력월 기준이라 사주 년/월주에 쓰면 오답 (일진은 정확).

## 2. 시각 보정 정책 (채택안)

- **진태양시**: 서울 경도 126.978 고정, manseryeok trueSolarTime 사용 (국내 관행은 일괄 −30분; 우리는 균시차 포함 정밀 보정).
- **서머타임**: 1948–1951, 1955–1960, 1987–1988 출생자 −1h (manseryeok IANA 자동 — 셀프테스트로 확인).
- **야자시**: `splitJasi` — 일주는 자정 경계, 23:30~00:30(보정 후)은 야자시. 자시 출생엔 "유파에 따라 일주가 달라질 수 있음" 1줄 고지 (`isJasiBirth` 플래그).
- **시간 모름**: 삼주(三柱) 분석 폴백. 시주 의존 서술(말년운 등) 출력 제거.

## 3. 용신 단순화 규칙 (MVP 확정)

억부 정밀 판정 대신: **오행 분포 최소치(결핍) = 보완 대상**을 1차 규칙, **조후(월지 계절 치우침)** 를 타이브레이크로. 판정 이유를 enum으로 노출 (`lacking` | `season_cold` | `season_hot`) → 카피의 근거 문장 생성용. "용신 보완(결핍→충족)" 서사가 국내 개운 콘텐츠의 지배 서사이며 설득력 최고.

## 4. 오행 ↔ 향 전통 근거표 (『황제내경』 오행 배당 + 국내외 자료 교차 정합)

| 오행 | 전통 배당 (색/계절/감정/오미/오취) | 향 노트 패밀리 번역 |
|---|---|---|
| 목(木) | 청/봄/성장/신맛(酸)/누린내(臊) | 그린(갈바넘·풀잎), 허브(바질·로즈마리), 시트러스 리프(페티그레인), 파인·포레스트 |
| 화(火) | 적/여름/열정/쓴맛(苦)/**탄내(焦)** | 스파이시(시나몬·클로브·핑크페퍼), 앰버, 인센스·스모키, 웜 바닐라 |
| 토(土) | 황/장하/안정/단맛(甘)/**향내(香)** | 우디 베이스(샌달우드), 어시(패출리·베티버), 파우더리, 스위트 발사믹, 허니 |
| 금(金) | 백/가을/수렴/매운맛(辛)/비린내(腥) | 알데하이드·클린, 화이트머스크, 아이리스(메탈릭), 시트러스 제스트, 민트 쿨 |
| 수(水) | 흑/겨울/지혜/짠맛(鹹)/썩은내(腐) | 아쿠아틱·마린, 워터리 플로럴, 딥머스크, 앰버그리스·솔티 |

오취(五臭)가 가장 직접적인 근거 축: 화=焦(탄내)→스모키/로스티드, 토=香(고소한 단내)→파우더리/스위트.
