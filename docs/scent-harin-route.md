# SCENT! 스핀오프 「하린 루트」 — 대본 초안 (2026-11-19)

키오스크 5~7분 한 판. 지금 SCENT! 영상판(`&lab=video`)과 같은 셸 · 장소 8곳 · 촬영 · AI 분석 · 영수증을 그대로 쓰고, 아래 대화판만 미연시 대사창 + 선택지로 바꾼다.
주소(예정): `/kiosk?mode=ai-perfumer&demo=1&lab=date`. 전체 이용가 · 설레는 정도의 건전한 로맨스. 손님 성별과 상관없이 자연스러운 대사. 한국어 먼저.

## 규칙

- **호감도 ♥**: 선택지마다 +2 / +1 / 0. 호감 질문은 5번(살롱 · 온실 · 증류실 · 오르간 · 랩) → 최대 10.
- **향 키워드**: 온실 · 증류실 · 오르간의 '키워드 질문'이 SCENT! 분석에 들어가는 스타일 · 성격 · 매력을 정한다(답 하나에 키워드 둘, 최대 3개 규칙 안).
- **엔딩**: ♥ 8~10 「설렘」 · 4~7 「단골」 · 0~3 「첫 손님」. 셋 다 향 레시피를 받는다.
- **반응 영상**: `설렘`(얼굴을 붉히며 시선을 살짝 피했다 돌아봄) · `웃음`(환하게 웃음) — 장소마다 둘, 4초, 첫 · 끝 프레임 = 장소 그림. 0점 답은 반응 영상 없이 대사만.
- `{이름}` 은 방명록에 쓴 이름(없으면 '손님'). 대사는 한 줄씩 타자처럼 찍히고, 화면을 누르면 다음 줄.
