## 마케팅 + 데스크톱 페이지

**모바일은 기존 먹빛 다크 그대로 두고, 데스크톱(lg 이상)만 아이보리+금색으로 전환**하는 방향입니다. 공용 페이지(faq, collaboration, about/brand, about/how-it-works)는 `lg:` 오버라이드를 얹었고, 데스크톱 전용 컴포넌트(HomeDesktop, ProductsDesktop)는 조건 없이 값을 바꿨습니다 — 후자는 ViewportSwitch의 desktop 슬롯에서만 렌더되므로 `lg:`가 애초에 불필요합니다.

- **섹션 리듬 전환**: '프로그램 둘러보기'·'오늘의 향 뽑기'·'상품 둘러보기' 배경 → `bg-[#FBF7EF]`. **'오늘의 향 뽑기'만 기존 `border-y-2 border-[#262A38]` → `border-b-2 border-[#D8CFBB]`로 교체됐고, 프로그램/상품 섹션에는 경계선이 새로 추가**됐습니다. 섹션 h2에 `font-heading` 추가 + `font-semibold` → `font-bold`.

## 차트 컴포넌트

- **특성 레이더 차트 팔레트 전면 크림화.** 10개 특성 전체가 배경 `#151823` → `#F5EFE2`(darkness `#232838` → `#EDE5D2`, purity `#0C0E16` → `#EDE5D2`), 글자 `#A69F8D` → `#5C564A`, 테두리 `#343A4C`/`#262A38` → `#D8CFBB` 단일 값으로 통일. **darkness와 purity 배경이 같은 값이라 두 특성 간 구분도 없어졌고, purity만 그라데이션(`to-[#E5DCC8]`)과 그림자(`shadow-[#D8CFBB]`)가 다릅니다.**
- **AI 말풍선 모션 2종 삭제**: 2.5초에 걸쳐 카드를 가로지르고 3초 쉬었다 반복되던(주기 약 5.5초) 흰색 반짝이 광택 레이어, 그리고 2초 간격으로 좌우 흔들리던 아이콘 박스 애니메이션. 아이콘 박스는 `bg-[#12141D]/90 + border-2 border-[#5C564A]` → `bg-[#EFE4C8] + border border-[#D8CFBB]`.
- **핸들·배지 톤다운**: @acscent_ai `font-bold` → `font-medium` + `text-white/80` → `#6E6659`, 점수 배지는 반투명 흰색 → 불투명 크림 + 테두리 추가.
- **최고점 강조 링 `ring-[#343A4C]` → `ring-[#A87B10]`** — 화면에서 유일하게 채도가 있는 포인트 컬러가 됐습니다.
- **키워드 클라우드는 테두리만 손댔습니다.** 8종 중 `border-2`를 쓰던 4종(⭐ 옐로우 스티커, 💜 라벤더 필 dashed, 💙 스카이블루 태그, 💕 코랄 스탬프)만 1px로. 민트 버블은 원래 1px, 나머지 3종은 테두리가 없습니다. **칩 배경·글자색은 다크 계열 그대로**입니다.
