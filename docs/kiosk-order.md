# Aible AI 주문 키오스크 (레퍼런스 · 2026-10-16)

외국인 관광객이 매장에서 쓰는 **AI 주문 키오스크**의 레퍼런스 앱이다. 사업계획서(제18회 관광벤처 공모 · 일해라컴퍼니 'Aible')의 손님 쪽 기능을 가상 매장 **모락 MORAK**(을지로 한식당, 1998)에 얹어 실제로 눌러 볼 수 있게 만들었다. 사장님용 셀프 구축 화면(v2.0)이 만들어 내는 결과물이 이 화면이라는 설정이다.

- 주소: `/kiosk/order` (손님 휴대폰 페이지: `/kiosk/order/m`)
- 화면: 560×996 CSS(매장 키오스크 1080×1920 그대로). 다른 크기에서는 9:16 무대째 비율을 맞춰 가운데에 놓는다 — 데스크톱 브라우저로 시연해도 같은 화면이다.
- 매장 키오스크 앱(JIMFF 셸)의 `config.json` `appUrl` 을 `https://www.acscent.co.kr/kiosk/order` 로 바꾸면 그대로 뜬다. 영수증 인쇄(`window.kiosk.printReceipt`)·관리자 PIN·앱 종료도 기존 키오스크와 같은 길을 쓴다.
- 기존 `/kiosk` 운영 모드·관리자 설정과는 엮지 않았다(별도 앱). NEANDER 워터마크도 깔지 않는다.

## 언어 — '많아 보이지만 넷'

화면 언어는 `ko · en · ja · fr` 넷뿐이다(`src/lib/kiosk/order/i18n.ts`, `ko` 가 원본 타입 — 번역을 빠뜨리면 빌드가 깨진다). 나라 고르기에서만 200여 나라가 보이고, 각 나라는 `countries.ts` 의 `ui` 로 넷 중 하나에 이어진다: 한국 → ko, 일본 → ja, 프랑스와 불어권 34곳(벨기에·스위스·룩셈부르크·모나코, 마그레브·서아프리카 등) → fr, 캐나다를 포함한 나머지 → en. 인사말·나라 이름(그 나라 말)·통화(참고 환율)는 나라마다 다르다.

손님은 어느 언어로 말해도 된다 — AI 낱말 사전이 네 언어를 다 알아듣고, 답은 화면 언어로 한다(프랑스어 화면에서 영어로 물어도 프랑스어 답).

## AI 는 어떻게 '도는 것처럼' 보이나

`src/lib/kiosk/order/ai-engine.ts` — 언어 모델을 부르지 않는 데이터 기반 엔진이다. 같은 질문에는 늘 같은 답을 하고, 매장 데이터에 없는 말은 지어내지 않는다(사업계획서 리스크 2 '알레르기 오답' 대응 논리와 같다).

1. **이해**: 네 언어 낱말 사전으로 메뉴 이름(별칭 포함)·알레르기 14종·식습관·매운맛·국적·인원·의도(추천·먹는 법·궁합·재료·예산·음료·근처 관광·담기 …)를 뽑는다. 긴 낱말부터 잡고 그 자리를 지워 'shellfish' 안의 'fish' 같은 겹침을 막는다. '이거 매워요?'의 '이거'는 바로 앞 메뉴.
2. **검색**: 메뉴판·재료표(84종, 숨은 재료 15종)·사장님 노트·나라별 주문 비율·매장 안내(FAQ 15)에서 찾는다.
3. **대조**: `diet.ts` 가 재료표로 알레르기·식습관을 판정하고, 옵션 조합(최대 64가지)을 다 돌려 '참치로 바꾸면 OK' 같은 해법을 찾는다. 화면 카드·상세·AI·주방 메모가 모두 이 결과를 쓴다.
4. **생성**: `ai-copy.ts` 의 네 언어 문장 틀에 찾은 값을 끼운다. 한국어 조사(은/는·으로/로)는 받침을 보고 고른다.

대표 시연 질문: "does kimchi stew have shrimp?" → '네 — 김치에 새우젓(갑각류)이 들어가요, 대신 된장찌개는 어떠세요?'(범용 AI 는 모르는 이 매장만의 사실).

## 디자인 · 성능

- 리퀴드 글라스: `.lg`(반투명 + 가장자리 반사광 + `backdrop-filter`), `.lg-strong`(짙은 유리), `.lg-press`(누른 자리에 빛이 맺힘 — `ui.tsx` `usePressGlow`). AI 요소는 무지갯빛(Apple Intelligence 풍) — 구슬, 'AI 추천' 글자, 생각하는 동안 시트 가장자리.
- 매장 PC(Celeron · Intel HD 510)를 생각해 `backdrop-filter` 는 떠 있는 작은 면(독·탭·알약·버튼)에만 건다. 시트·모달은 흐림 없는 짙은 유리, 화면 전환은 흐림 없이 투명도·크기만. 무지갯빛 테두리는 AI 가 생각하는 동안에만 돈다.
- 움직임은 `prefers-reduced-motion` 을 따르지 않는다(`MotionConfig reducedMotion="never"`, CSS 에도 reduce 블록 없음) — 매장 PC 는 윈도우 애니메이션이 꺼져 있어 늘 reduce 로 알린다(키오스크 공통 함정).
- 글꼴: 한·영·불은 Pretendard(사이트 전역 `--font-heading-serif`), 일본어는 Noto Sans JP(`src/app/kiosk/fonts.ts`).

## 한계 · 남은 것

- 결제·주방 연동·주문 저장은 없다(데모). 휴대폰 페이지의 주문 상태는 주문 시각과 조리 시간으로 계산한다.
- 3D 모델 6종(`three/`)은 사진에서 생성한 것이 아니라 손으로 짠 절차적 모델이다. 휴대폰 페이지는 3D 보기까지이고 WebXR 탁자 위 배치(AR)는 하지 않는다.
- 음성 입력은 브라우저 음성 인식(Web Speech API)이 있을 때만 된다. 매장 키오스크(Electron)에서는 '쓸 수 없다'고 안내하고 자판을 연다.
- 환율은 참고값(2026년 기준 근사)이다.
