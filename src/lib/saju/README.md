# 사주 계산 엔진 (`src/lib/saju/`)

> **대원칙: AI는 사주를 계산하지 않는다. 이 엔진이 계산하고 AI는 해석만 한다.** (DESIGN.md §3)
> 모든 함수는 순수 함수 — `Date.now()` 등 실행 시점 의존 없음. 동일 입력 → 동일 출력.

## 모듈 구성

| 파일 | 역할 |
|---|---|
| `types.ts` | `SajuChart`·`Pillar`·`Element('목'\|'화'\|'토'\|'금'\|'수')` 등 전 타입 |
| `calendar.ts` | 율리우스일(JDN)·60갑자 일진·년두법/월두법(오호둔)/시두법(오서둔)·지장간·십성·합충형해파 테이블 |
| `solar-terms.ts` | 12절(입춘~소한) 절입 시각 (KST) — 년주/월주 경계 |
| `lunar.ts` | 음력(윤달 포함) ↔ 양력 변환 |
| `chart.ts` | `computeSajuChart()` / `computePairRelations()` — 원국·오행분포·신강약·용신·궁합 |
| `scent-map.ts` | 오행→향 매핑 SSOT (30종 전수) + `getScentCandidates()` |
| `__selftest__.ts` | 자체 검증: `npx tsx src/lib/saju/__selftest__.ts` (93+ 어서션) |

## 계산 코어 선정

- **주 엔진: npm [`manseryeok`](https://www.npmjs.com/package/manseryeok) v2.0.0 (MIT)** — KASI(한국천문연구원) 계열 분 단위 절기 데이터(1800~2300), 음양력 변환(1391~2100, 윤달), 진태양시(경도+균시차)·과거 표준시/서머타임 자동 보정, `dayBoundary` 3모드 지원. 리서치 dossier 권고에 따라 채택.
- **교차 검증(셀프테스트 전용): `korean-lunar-calendar` v0.4.0 (MIT, devDependency)** — 음양력 변환·일진 갑자를 무작위 300일에 대해 대조. 두 라이브러리가 전 앵커에서 일치함을 확인 후 manseryeok 단일 SSOT로 결정.
- **절기 3중 검증**: ① KASI 발표값 앵커(2024 전 절기·1990/2025/2026 입춘 분 단위 일치) ② 셀프테스트에 내장한 **독립 Meeus 태양황경 근사**(행성 섭동항+ΔT)와 1930~2035 전 구간 대조 — 최대 편차 **5분 이내** (요구 스펙 ±30분) ③ 일진 앵커(위키백과 갑자일 수열, (JDN+49) mod 60).

## 규약 결정 (전부 셀프테스트로 고정)

| 항목 | 결정 | 근거 |
|---|---|---|
| 시간대 | KST 고정 입력 (벽시계 시각) | 서비스 대상 = 한국 출생 |
| 진태양시 | **서울 경도 126.978°E + 균시차(EoT) 보정** (`trueSolarTime` 옵션) | 일괄 -30분 근사보다 정확 (경도 -32.1분 + 균시차 -14~+16분 계절 변동). dossier 확정 |
| 서머타임 | 1948~1951·1955~1960·1987~1988 자동 -1h (manseryeok IANA 처리, 1988-07-15 케이스 검증) | 국가기록원/위키 확인 날짜와 일치 |
| 1954-03-21~1961-08-09 | 당시 표준시 UTC+8:30 자동 반영 (1958-06-15 케이스 검증) | 한국 표준시 변천사 |
| 시지 경계 | 자시 23:00~01:00 시작, 2시간 간격 (보정 후 시각 기준) | 정통 다수설 |
| 일 경계 | **`splitJasi`** — 일주는 자정(00:00) 경계 유지, 23시대(보정 후) 출생의 시주 천간만 익일 일간 기준 | 국내 만세력 앱 관행. dossier 확정 (초기 스펙 '자시=익일'에서 변경) |
| `isJasiBirth` | 보정 후 시지가 자시(23:00~01:00)면 true — UI가 "유파에 따라 일주가 달라질 수 있음" 고지 | dossier §6 (23:30~00:30 위험구간의 안전 상위집합) |
| 년주 경계 | **입춘 절입 시각** exact datetime 비교 | 명리 표준 |
| 월주 경계 | 각 절(節) 절입 시각 exact datetime 비교 | 명리 표준 |
| 절기 비교 시각 | **표준시 순간 그대로** (진태양시 보정 미적용 — 절입은 지구 공전상 절대 순간) | 시주/일주만 지역 태양시 개념 |
| 시간 모름 | 년/월/일주는 정오(12:00) 기준 계산, 시주 `null`, `isThreePillar=true`, 오행 6유닛 | 정오는 일 경계에서 가장 먼 시각 |
| 서비스 범위 | 1930~2035년 (라이브러리 자체는 더 넓음) | DESIGN.md §3 |

## 파생값 규약

- **오행 분포 `elementCount` (지장간 가중)**: 천간 글자당 1.0, 지지 글자당 1.0을 **지장간 일수비(예: 인 = 무7/병7/갑16 → 토 7/30·화 7/30·목 16/30)**로 분배. 총합 = 8.0(사주) / 6.0(삼주). `rawElementCount`는 겉글자 그대로 정수 집계.
- **십성**: 일간 제외 천간 3(2) + 지지 4(3)의 **본기 지장간** 기준 (자→계, 오→정 등 용사 기준). 합계 7(삼주 5).
- **신강약**: 득령(월지 본기가 비겁/인성, +3)·득지(일지 본기, +2)·그 외 글자(년간·월간·시간·년지·시지 본기) 개당 +1. 만점 10(삼주 8). 비율 ≥0.55 신강 / ≤0.38 신약 / 사이 중화. `deukse`는 그 외 글자 중 60% 이상 지지 시 true.
- **용신 (dossier 확정 단순 규칙)**: ① 1차 = 가중 오행 최소치(결핍) 보완 → `reason: 'lacking'` ② 동률(±0.01) 타이브레이크 = 조후: 겨울(해자축월)생이면 화 우선 `'season_cold'`, 여름(사오미월)생이면 수 우선 `'season_hot'` ③ 잔여 동률은 목화토금수 순. `reasonText`(한국어 근거 문장)와 `heesin`(용신을 생하는 오행) 포함.
- **결핍/과다**: 결핍 = 가중치 < 총량×12.5% (없으면 최소 1개), 과다 = ≥ 총량×28% (없으면 최대 1개). `lackingElements`가 "부족한 기운을 향으로 채운다" 서사의 근거.
- **지지 관계**: 육합(오미합은 화로 처리)·삼합·반합(왕지 포함 2자, 완성 삼합의 부분합은 중복 보고 안 함)·충·형(인사신/축술미 부분형 포함, 자형 포함)·해·파. 인사=형+해, 사신=육합+형+파처럼 **중복 관계는 전부 개별 보고** (원전 그대로 — AI가 긴장 관계 서사에 활용).
- **궁합 `computePairRelations`**: 두 원국 천간 4×4 천간합 + 지지 4×4 육합/반합/충/형/해/파 전수 스캔, `iljiRelations`(일지↔일지)·`ilganHap`(일간합) 강조 추출. `elementComplementScore` = 합산 분포의 오행 균형도(각 20% 이상적, 편차 최대 1.6 기준 0~100). `mutualFill` = 한쪽 결핍을 상대 과다가 채우는 오행.

## 오행→향 매핑 (`scent-map.ts`)

전통 상응: 목=그린/허브/침엽(생장), 화=스파이시/웜/스모키(발산), 토=스위트/파우더리/흙·무화과/바닐라(안정), 금=시트러스/클린/화이트플로럴(수렴), 수=머스크/아쿠아틱/심연(응축).

**분포 (primary 기준): 목 8 · 화 6 · 토 4 · 금 8 · 수 4** — 전 오행 4종 이상 보장. 30종 모두 실제 노트(main/sub1/sub2) 근거의 한국어 1문장 rationale 포함. `getScentCandidates(용신, 결핍[])`이 용신 primary 100 / secondary 40, 결핍 primary 30 / secondary 12 점수로 후보를 랭킹(기본 8종, 동점은 id 순 — 결정적).

## 사용처 가이드 (번들)

manseryeok 데이터 테이블은 절기 14KB + 음양력 9KB (raw, gzip 시 ~10KB) 수준으로 크리티컬하진 않지만, **권장 사용처는 서버(API route / 서버 액션)** — `/api/analyze/saju`가 차트를 계산해 프롬프트에 주입하고, 로딩 오버레이의 8글자 플립은 그 응답(또는 제출 직후 경량 서버 액션)으로 받는다. 클라이언트에서 직접 import해도 동작은 하나(순수 함수, Node API 없음) 번들 증가를 감수해야 하므로 지양.

## 검증 방법 재현

```bash
npx tsx src/lib/saju/__selftest__.ts   # 93+ 어서션: 전부 PASS여야 함
npx tsc --noEmit                        # 타입 무결성
```

주요 외부 앵커: 2024 전 절기 KASI 시각(입춘 02-04 17:27 등), 1990 입춘 02-04 11:14 경계(10:30생 기사년 정축월 / 11:30생 경오년 무인월), 일진 앵커(2024-01-01 갑자·2000-01-01 무오·1949-10-01 갑자), 1995-08-15 04:30생 = 을해 갑신 무인 갑인, 설날 1990-01-27/2024-02-10/2025-01-29, 2023년 윤2월 1일 = 03-22.

## 정확도 주의사항

- 절기 시각은 KASI 발표값과 분 단위 일치(검증 앵커 기준). 발표값 자체가 분 단위 반올림이므로 절입 ±1분 이내 출생은 이론상 경계 모호 — 실무 영향 없음.
- 1948~1960 서머타임 시행/해제 당일 전이 시각(00시/24시) 부근 출생은 사료상 모호성이 있음 (manseryeok의 IANA 규칙을 따름).
- 진태양시는 서울 경도 고정 — 출생지 경도 입력은 현 스펙 밖 (부산 등은 ±8분 내외 차이, 시지 경계 근접 출생만 영향).
- `splitJasi`는 국내 관행이지만 유파 차이가 실존 — `isJasiBirth` 플래그로 UI 고지 필수.
