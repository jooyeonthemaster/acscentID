# LATER! 미래로 가는 타임캡슐 — 포토 프레임 10종

2026 안산사이언스밸리 과학축제 AI 포토존용 오버레이입니다. `codex_프레임_생성_프롬프트.md`의 좌표 계약에 맞춰 제작했습니다.

[10종 한눈에 보기](contact-sheet.jpg) · [확대 갤러리](index.html) · [manifest](manifest.json) · [픽셀 검사 결과](validation-report.json)

## 파일 구성

- `frames/`: 글자 없는 1200×3600 RGBA PNG 10장. 실제 사진 창은 투명하며 sRGB ICC 및 600dpi 메타데이터를 포함합니다. 모두 2MB 미만입니다.
- `thumbs/`: 240×720 무손실 WebP 10장. 사진 창의 투명도를 유지했습니다.
- `previews/`: 회색 가족 도형으로 된 예시 사진 4칸과 예시 글자를 합성한 JPEG 10장. 실제 촬영 사진이나 미래 변환 결과는 포함하지 않습니다.
- `contact-sheet.jpg`: 미리보기 10장 모음, 3000×3900.
- `index.html`: 파일을 직접 열어 사용하는 확대 갤러리. 완성 예시와 투명 프레임을 전환할 수 있습니다.
- `manifest.json`: 프레임 ID, 경로, 한국어 이름, 참고 구도, 밝기 구분, 글자·연도 이름표 색상. `background`, `thumb`, `preview`는 추가 편의 필드입니다.
- `coordinate-contract.json`: 사진 창, 안전 영역, 글자 구역 좌표.
- `assets/`: 새로 생성한 투명 일러스트 11장과 실제 생성 프롬프트·생성 기록.
- `scripts/`: 프레임 조립, 미리보기 제작, 픽셀 검사 스크립트.

배경·패턴·기호, 배치, 창 마스크, 파일 메타데이터는 Python/Pillow로 조립했습니다. 코드로 그리는 선의 기준 두께는 3px 이상입니다. 생성 일러스트는 축소 가독성을 위해 굵은 선을 사용했으며, 실제 프린터에서의 출력 교정은 수행하지 않았습니다.

## 좌표 계약

좌표는 오른쪽·아래 끝을 제외하는 반열린 구간입니다. 예를 들어 첫 창은 `x=92..1107, y=120..797`입니다.

| 칸 | 창 `[x0, y0, x1, y1)` | 완전 투명 안전 사각형 |
|---|---|---|
| 2026 | `[92, 120, 1108, 798)` | `[132, 160, 1068, 758)` |
| 2036 | `[92, 826, 1108, 1504)` | `[132, 866, 1068, 1464)` |
| 2046 | `[92, 1532, 1108, 2210)` | `[132, 1572, 1068, 2170)` |
| 2056 | `[92, 2238, 1108, 2916)` | `[132, 2278, 1068, 2876)` |

- 기본 창 반지름 28px. 로봇 친구의 물결은 창 가장자리 40px 띠 안에서만 변형합니다.
- 각 안전 사각형 936×598px의 모든 픽셀은 alpha 0입니다.
- 네 창 사각형 바깥의 모든 픽셀은 alpha 255입니다. 필름 스프로킷은 투명 구멍이 아닌 인쇄 무늬입니다.
- 연도 이름표 자리 `x=132..559`, 각 창 하단 기준 위로 140..40px는 비워 두었습니다.
- 아래 글자 구역 `[160,2970,1040,3470)`은 프레임별 단색입니다.
- 주요 캐릭터는 창 옆 `x=72..127` 또는 `1072..1127`, 아래 양옆 `x=74..155` 또는 `1044..1125`에 배치했습니다. 바깥 72px 재단 여백을 지킵니다.

밝기는 `0.2126R + 0.7152G + 0.0722B`로 계산했습니다. 글자 구역이 단색이므로 표준편차는 모두 0입니다. JPEG 미리보기의 압축 오차가 아닌 실제 PNG를 검사한 값입니다.

시각 확인도 완료했습니다. 10종 컨택트 시트와 개별 이미지, 주요 그림의 배치 좌표를 함께 확인했습니다.

- 바깥 72px 띠에는 잘려도 되는 반복 배경과 장식 무늬만 있습니다. 주요 캐릭터·천문대·축하 그림은 이 띠 안으로 들어가지 않습니다.
- 각 창에 걸치는 마스코트는 최대 1개, 최대 배치 상자 56×112px입니다. 계약의 칸당 3개·각 120×120px 제한 이내입니다.
- 캐릭터의 얼굴과 몸이 잘리지 않고, 중앙 얼굴 영역 및 연도 이름표 영역을 가리지 않습니다.
- 실제 PNG에는 글자·숫자·로고·워터마크가 없습니다. `LATER!`, 행사명, 날짜와 연도는 확인용 JPEG에만 있습니다.
- 아래 제목과 안내 문구는 깨끗한 배경 위에서 읽힙니다. manifest의 흰색/짙은 글자색을 해당 배경에 맞춰 선택했습니다.

자동 검사 스크립트는 시각 판단을 자동화했다고 주장하지 않습니다. 재생성 후에는 위 시각 확인도 다시 해야 합니다.

## 부스 코드에서 사용하기

1. 선택한 manifest 항목의 `file`을 프레임으로 로드합니다.
2. 사진 네 장을 계약 좌표에 먼저 그립니다.
3. 투명 PNG 프레임을 그 위에 원본 크기로 합성합니다.
4. 연도 이름표와 아래 글자를 manifest의 `colors`로 그립니다.
5. 최종 합성본을 600×1800으로 축소해 300dpi 원판으로 사용합니다. 이때 모든 좌표를 0.5배 적용합니다.

미리보기 JPEG를 실제 오버레이로 사용하면 회색 예시 사진과 글자가 함께 인쇄됩니다. 실제 합성에는 `frames/`의 PNG를 사용합니다.

## 재생성

기존에 생성된 `assets/`를 사용하므로 아래 명령은 이미지 모델을 다시 호출하지 않습니다.

```bash
python3 ansan-frames/scripts/build_frames.py
python3 ansan-frames/scripts/build_previews.py
python3 ansan-frames/scripts/validate_frames.py
```

Python 3, Pillow, numpy가 필요합니다. 제작 환경은 macOS, Pillow 9.5.0, numpy 1.21.6입니다. 미리보기 한글에는 macOS의 Apple SD Gothic Neo, 영문 제목에는 Arial Bold를 사용합니다. 다른 운영체제에서 미리보기를 다시 만들 경우 `build_previews.py`의 폰트 경로를 설치된 한글 폰트로 지정합니다. 실제 프레임 PNG는 폰트를 포함하지 않습니다.

## 저작권 메모

참고 01~10에서 가져온 것은 색 계열, 패턴 종류와 배치 방식 등 구도뿐입니다. 원본 참고 이미지의 픽셀, 캐릭터, 닮은꼴을 의도한 디자인, 고유 상징, 로고, 작품명, 워터마크는 결과물에 사용하지 않았습니다. 실제 기관 로고도 넣지 않았습니다. 생성 일러스트는 이 작업을 위해 새로 만들었으며, 패턴과 기호도 코드로 새로 그렸습니다. 참고 원본 이미지는 배포 폴더에 포함하지 않았습니다.

## 제안

현재 계약에서는 재단 안전 여백 72px와 아래 글자 구역 사이에 주요 그림을 놓을 수 있는 폭이 약 88px뿐입니다. 따라서 마스코트는 사진·안내를 방해하지 않는 작은 장식으로 배치했습니다. 큰 캐릭터를 강조하는 별도 버전이 필요하다면 글자 구역 폭이나 사진 창 좌표부터 함께 설계하는 것이 좋습니다. 이번 결과물의 좌표 계약은 변경하지 않았습니다.
